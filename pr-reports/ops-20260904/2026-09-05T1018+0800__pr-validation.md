## 验证方法与口径

- **基线策略**：工作树钉在发布 tag，把每个 open PR 3-way merge 到 tag（= tag + 该 PR 的 kernel），逐 PR 隔离。
- **构建**：`COMPILER_DIR`/`LINX_SYSROOT` 指向 env_test 工具链，逐目标目录 `bash compile.all`；每 PR 编译前清 `output/`（防陈旧 ELF）。
- **运行**：逐 ELF `gfrun`+`gfsim`；每个 ELF **裸跑失败再试 4PE，任一通过即 PASS**（`gfrun -s softcore.multiThreadNum=4` / `gfsim --conf fourpe.conf --pto-v02 true`），以规避 4PE 漏配假失败。
- **判定**：`PASS`=rc0 且无 ASSERTION；`TIMEOUT`=rc124；`FAIL`=其余非零/断言/崩溃；`COMPILE_FAIL`=该目录 compile.all 未产出对应 ELF。
- **职责边界**：只报可用性 + 断言 `file:line`，不诊断根因；仅对「明显与工具版本无关」的失败予以点明（防误归因）。
